# 🌌 Goutam Patel - Advanced Portfolio Website

A modern, premium personal portfolio website built using **HTML5, Advanced CSS3, and JavaScript (Scroll Reveal)**.

This portfolio features a **glassmorphism UI**, animated gradient background, smooth scroll reveal animations, and a futuristic developer theme.
